IMPORTANT: GITHUB 404
The screenshot shows GitHub's 404 page at the profile URL. This can mean the username/URL is wrong or the profile/repository is not publicly accessible. First open https://github.com and sign in, then click your avatar > Your profile and copy the exact profile URL. Do not assume the profile URL works just because it was typed into the portfolio.

HOW TO PUBLISH
1. Upload these four files (not the ZIP itself) to a public GitHub repository.
2. Make sure index.html is in the repository root.
3. Import that repository into Vercel and deploy.
4. If you update the repository connected to Vercel, Vercel normally redeploys automatically.

ADD PROJECTS / DOWNLOADS
- Add each real project to its own GitHub repository.
- Upload a ZIP release or use GitHub's Code > Download ZIP for public repositories.
- Update a project card's repository/download URL in index.html.
- Do not upload .env files, passwords, API keys, private data, or client secrets to public repositories.


UPDATED INTERACTIONS
- Scroll reveal animations are restored.
- The technology background slowly drifts/zooms.
- Cursor spotlight is larger and brighter; particle sparks are larger and linger about 1–2 seconds.
- Tap the + icon in the project section to choose files from your computer. A project card and per-file download links are created in the current browser session.

IMPORTANT PROJECT-UPLOAD LIMITATION
The + feature is a local preview feature, not a server upload. Files selected from your computer are not automatically sent to GitHub/Vercel and won't appear to other visitors. For a public website, upload the project files to the GitHub repository and redeploy. The portfolio itself can be published as a static website, but check all profile/repository links, content, mobile layout, and external assets before calling it production-ready.
